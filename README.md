2. Analisislah pada gambar kenapa saat instalasi perlu dipilih “/” pada opsi Mount Point ?
Jawab = Mount Point “/” perlu digunakan karena merupakan root directory atau direktori utama dalam sistem Linux. Root berfungsi sebagai tempat awal penyimpanan berbagai direktori penting seperti /etc, /usr, /var, dan /home. Dengan adanya Mount Point “/”, sistem operasi dapat memiliki lokasi utama untuk menyimpan dan menjalankan seluruh komponen sistem.

3. Berikan penjelasan tentang ext4, ext3, swap, ntfs, fat32,btrfs !
Jawab =
• Ext3 merupakan sistem file pada Linux yang sudah digunakan sebelum Ext4. Ext3 memiliki fitur journaling yang berguna untuk membantu menjaga konsistensi dan keamanan data apabila terjadi gangguan seperti mati listrik atau sistem mengalami crash.
• Ext4 adalah pengembangan dari Ext3 yang memiliki performa, kapasitas, dan kemampuan pengelolaan file yang lebih baik. Ext4 menjadi salah satu sistem file yang umum digunakan pada sistem operasi Linux.
• Swap merupakan bagian dari media penyimpanan yang digunakan sebagai memori virtual. Swap akan membantu sistem ketika kapasitas RAM yang tersedia sudah tidak mencukupi untuk menjalankan proses.
• NTFS (New Technology File System) adalah sistem file yang dikembangkan oleh Microsoft dan banyak digunakan pada sistem operasi Windows. NTFS mendukung penyimpanan file berukuran besar serta memiliki fitur seperti permission dan journaling.
• FAT32 (File Allocation Table 32) adalah sistem file yang memiliki tingkat kompatibilitas tinggi dan dapat digunakan pada berbagai sistem operasi seperti Windows, Linux, dan macOS. Namun, FAT32 memiliki keterbatasan, salah satunya adalah ukuran maksimal satu file sekitar 4 GB.
• Btrfs (B-tree File System) merupakan sistem file Linux modern yang menyediakan berbagai fitur tambahan seperti snapshot, kompresi data, pengecekan integritas data (checksumming), dan subvolume. Sistem ini cocok digunakan ketika membutuhkan pengelolaan data yang lebih fleksibel dan fitur pemulihan yang lebih lengkap.
